## 项目简介

CatalogGuard 在译文合入前检查源文与译文的格式参数合同。相对 moongettext，本次申报的净增范围集中于 C printf、Python str 百分号格式和 Python str.format 三类检查器，识别参数缺失、多余、用途变化及非法边界语法，并允许保持参数身份和用途的合法重排。PO/POT、目录校验、复数、统计和模板处理属于与既有库重叠的共性能力，不申报为独有创新。

检查核心由 MoonBit 实现，Node.js 负责命令行与文件输入输出。提供公开 API、带源位置的诊断、JSON 报告及明确退出码。本次改进源码版本为 0.1.2；历史 Mooncakes 0.1.1 已发布，两个版本的验证结果分别记录。

## 核心功能范围

- C 格式目标为 C11 WG14 N1570 7.21.6.1 的 printf 静态合同，加 POSIX 编号参数。覆盖顺序/显式身份、length 与转换族、动态宽度精度依赖及已知未定义组合，列明额外 GNU 支持及排除项。
- Python 百分号格式目标为 Python 3.12 的 str 格式。覆盖字典/顺序实参、空键与 Unicode 键、动态星号、转换族及重复用途；合法字典键重排可接受。
- Python brace 目标为 Python 3.12 str.format 的字段和内建规格。覆盖自动/编号路径、属性下标、Unicode 名称与数字身份、转义、转换、一个嵌套字段层及动态依赖；拒绝过深嵌套与已知非法内建组合。
- 合同按参数身份和用途集合比较，允许合法重排及相同用途重复。完整兼容终点为 CGFC-1 内全部语法产式、类型组合、资源边界的实现和正反案例覆盖，并在两后端与发布消费项目中复验；目前不宣称全规范兼容已完成。
- 本次新增 96 个分类案例，连同原有 37 项共 133 个核心用例，在 JS/Wasm GC 各通过；19 项 CLI 测试、真实打包的独立 consumer、55 项 CPython 3.12.14 运行探针均通过。73 项 GNU 1.0 固定交叉预期通过，另外 23 项仅观察；参考工具与规范的差异明确列出。
- 对 moongettext 的固定提交开展公开 API 对照：三种格式错配均在其目录校验范围之外，本项目能报告 F005；重复键控制确认其校验在运行。四个探针通过，未修改或复制对方代码。
- 提供可直接运行的合法重排和错误 PO 文件、机器可读案例源、生成的两后端回归测试、独立验收脚本、来源及许可证说明。具体案例、标准来源、兼容终点和未完成项见 docs/FORMAT_CONTRACTS.md 与 docs/REVIEW_RESPONSE.md。

## 移植或参考说明

本项目为原创 MoonBit 实现，参考 C11/POSIX、Python 3.12 及 gettext 格式概念，未复制 GNU gettext、polib、moongettext 或 Translate Toolkit 的实现代码。采用 Apache-2.0。第三方工具与外部语料仅用于独立对照，不作为运行时依赖或计入本项目生产代码。

项目使用 AI 辅助设计、实现、测试和文档，提交者对最终成果和维护负责。复审材料区分已实现能力、案例验证、历史发布和后续兼容目标，不将有限案例通过表述为全语言或任意对象执行的全面兼容。
