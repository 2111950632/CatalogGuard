## 已处理的问题与实现边界

1. **忽略上下文后的正向冲突漏报**：首个源条目无法代表同文件多个 context 的译文、复数源文和 flags。现分维度保留有界见证，查询必须同时满足不同文件、不同值。每维度每组至多五项；每个当前条目每条规则至多一个见证，X003/X002 可分别引用不同条目，不枚举全部冲突配对。
2. **HTML 数字引用属性误报/漏报**：按 [HTML numeric character reference end state](https://html.spec.whatwg.org/multipage/parsing.html#numeric-character-reference-end-state) 对 27 个 C1 引用重映射，例如 128→欧元符号；XML 保留原码点。独立 HTMLParser 和 ElementTree 检查模式差别；NUL、代理区和超范围引用继续明确拒绝，不实现浏览器全部错误恢复。
3. 保留 0.2.1 的属性 CRLF/CR 规范化、非法语言分组和逆向冲突修复。C013 人工审阅提示仍独立生效，不把标记合同相等当作所有目录规则通过。
4. 维持 MoonBit 检查核心、Node 输入输出边界、旧公开 API 及 JSON schema_version=1；资源限制明确失败。源码、生成接口、测试、宿主和外部语料分别统计。
