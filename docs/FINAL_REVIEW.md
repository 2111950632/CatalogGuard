## 已处理的问题

1. **属性 CRLF 误报**：原版本将 XML 属性中的一次 CRLF 当作两个空格，导致与合法等价属性不一致。现按 XML 1.0 §2.11/§3.3.3 和 HTML 输入流预处理处理字面行尾，保留字符引用的 CR；ElementTree 属性对照独立验证。原有 C013 人工审阅规则继续生效。
2. **非法语言分组**：原版本接受纯数字语言、空子段等输入，可能产生无意义的跨文件冲突。现拒绝这些输入并给出 X001；保留脚本、地区和数字子段，明确不做注册表或完整 gettext locale 验证。
3. **逆向冲突遗漏**：原版本只记每个译文的第一个源文，可能漏掉其他源文的跨文件见证。现每组至多保留五个代表，要求文件与源文均不同，每个当前条目最多报告一个逆向见证。729 个小项目与朴素双层参考比较一致；729 是一个测试内的输入排列数量，不虚报为 729 个核心测试。
4. 缓存源条目的译文和 flags 合同，按文件分发 findings，避免重复构造与逐文件扫描全体诊断。固定 31 文件、7750 条消息、4 个复数槽位、约 4.96 MB 输入的工作负载，核对 7500 个预期冲突及关联文件。记录时间和响应后的 RSS，不以单次运行宣传倍数提速，不将 RSS 误称峰值内存。
5. 修正发布说明中的旧仓库地址/0.1.1 信息，版本号与 CLI/JSON 同步为 0.2.1。旧版成果不改写为新版成果。
