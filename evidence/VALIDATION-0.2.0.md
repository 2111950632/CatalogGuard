## 2026-10-19 CI 接口比较修复

线上运行 39231654419 的工具链为 moon/moonc 2026-10-16。用户提供的完整失败片段表明 check、fmt --check、info 均成功；失败来自生成接口将 `Int` 输出为 `Int32` 后的原样 Git 比较。官方语言文档明确二者为同一类型的别名：[Fundamentals](https://docs.moonbitlang.com/en/latest/language/fundamentals.html)。

新增接口检查仅容许未限定内建类型位置上的 Int/Int32 写法等价及 CRLF；其他内容仍精确比较。字符串、注释、标识符、包限定类型不会被替换；遇到自定义同名类型、泛型声明或 using 声明时保守回退到精确比较。此脚本用于本仓库，不宣称是通用 MoonBit 解析器或 API 兼容性分析器。

7/7 个 CI 辅助测试通过，覆盖实际整份接口的 Linux 写法、Int64 变化、字段删除、参数更名、新增导出、字符串/注释/限定名、自定义或泛型遮蔽，以及真实临时 Git 仓库的暂存变更、未跟踪/删除接口和带空格路径。两个已提交接口均通过检查。这 7 项不计入上述 222 个 MoonBit 核心或 29 个 CLI 测试。

本地另使用 2026-10-16 编译器和对应标准库完成全后端 check --deny-warn 与 info；Windows 调度使用 2026-10-12 moon，以绕过新 Windows 驱动的扩展路径异常。线上 Linux 仍使用官方当前完整工具链，其最终结果需上传本次修复后另行核对。CI 现在保留 core-verification.txt，便于从验证产物定位后续失败。生产 MoonBit 源码与已发布 0.2.0 包未改变。
